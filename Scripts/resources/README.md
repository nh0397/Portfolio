# Portfolio source files

These are public, editable inputs for `Scripts/sync_portfolio.py`.

The initial resume.json and linkedin.json were reconstructed from the checked-in
frontend snapshot dated 2026-08-09. They preserve existing content, and are not
freshly fetched LinkedIn/resume data. Add a text-based `Resume.pdf` here to use it
instead of resume.json. PDF parsing requires GOOGLE_API_KEY.

Edit featured-work.json for curated project narratives and demo videos. GitHub
repository cards are fetched automatically; no entry here is required for those.
See ../README.md for the complete workflow and configuration.
