# Frontend

| Folder | Status | Stack |
| --- | --- | --- |
| `portfolio/` | **Active** — this is the site | React 19 + Vite |
| `archive/vscode-themed/` | Archived | React + CRA |
| `archive/simple-react/` | Archived | React + CRA |

Only `portfolio/` is maintained. The two archived apps are kept for reference
and are not built or deployed.

## Running the site

```bash
cd portfolio
npm install
npm run dev          # http://localhost:5173
```

The assistant needs the Flask backend:

```bash
cd ../../Backend
python app.py        # http://localhost:5001
```

`VITE_CHAT_API_URL` in `.env.development` / `.env.production` points the
assistant at that backend.

## Where the content comes from

Facts on the page — roles, dates, education, awards, repositories — are **not**
hand-written. They live in `portfolio/src/data/portfolioData.json`, generated by
the backend:

```bash
cd Backend && python ingest.py
```

That one command rewrites the vector index the assistant searches *and* the JSON
this site renders, so the page and the chatbot can never disagree. To change a
fact, edit `Backend/data/{resume,linkedin,github}.json` and re-run it. Use
`python ingest.py --export-only` to refresh the site without touching MongoDB.

Everything a résumé can't carry — project narratives, demo videos, the skill
taxonomy — lives in `portfolio/src/data/content.js` and is edited by hand.

## Notes

- Skill strength bars in the Skills section are computed, not asserted: each one
  counts how many roles, projects and repositories in the generated data mention
  that skill (`src/lib/skillEvidence.js`).
- `src/assets/secure-sense.gif` is ~6 MB. It only loads when its project card is
  expanded, but it is the single heaviest asset here and is worth re-encoding to
  MP4/WebM if it ever moves above the fold.
